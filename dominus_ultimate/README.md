# DOMINUS ULTIMATE

DOMINUS ULTIMATE is the V23 architecture and implementation contract for the Phish-Hunter URL & Domain Analyst. It follows the supplied DOMINUS blueprint: 22 major modules, a seven-round passive-first pipeline, silent AI metadata, an isolate engine, global map interactions, a 200+ integration target, and explicit evidence/provenance.

Important: counts in catalogs are capability contracts/catalog entries. They do not mean 500 external providers are live. External data is only displayed when the connector is configured, authorized and reachable.

The runtime remains `phishhunter/url_domain_analyst`; this directory contains the complete production architecture, schemas, API contracts, deployment plans and generated capability registries.
