PHISH-HUNTER-K4 · PROJECT

A free, open-source defensive security platform.

Phish-Hunter is an engineering project built to bring practical phishing, malware, network-evidence, IOC and threat-intelligence analysis into one understandable workspace. It is designed for authorized defensive security work, education, research and self-hosted environments.

01

What it is built for

K4 is intended for security learners, SOC analysts, incident responders, researchers and defenders who need a repeatable workflow for suspicious artifacts. The platform connects collection, analysis, evidence, correlation, cases and reports.

  • Phishing and suspicious URL investigation
  • Email and attachment evidence review
  • Static file and malware triage
  • PCAP and network artifact analysis
  • IOC extraction and correlation
  • Threat-intelligence enrichment
02

Why it is being built

Many security tools solve one part of an investigation. The purpose of K4 is to connect those parts into a single workflow without making the evidence disappear behind a black-box verdict.

The project also serves as an engineering and learning environment: the source code, analyzers, web application, data model and documentation can be inspected and extended.

03

How it is built

The application uses a native Python web stack with FastAPI, SQL-backed persistence, server-rendered templates and modular analyzers. The same identity database is shared between the normal website and the administrator control plane.

WebFastAPI + server-rendered HTML
IdentitySQL user records + signed sessions
AnalysisModular local analyzers and enrichment
EvidenceScans, IOCs, cases, reports and audit data
04

Free and open source

The project is intended to remain free to use and open for learning, self-hosting and defensive development. There is no requirement to depend on a commercial SaaS subscription for the core local analysis workflow.

External services can be optional integrations. A self-hosted deployment can keep its investigation data within infrastructure controlled by the operator.
