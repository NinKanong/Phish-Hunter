# V22 Upgrade — Global Domain Intelligence

V22 expands the isolated URL & Domain Analyst into a deep domain-registration, DNS, infrastructure and geography investigation surface.

## Registration

The result now explicitly exposes Domain / Registered On / Expires On / Updated On / Status / Name Servers, followed by registrar and registrant fields. RDAP/WHOIS privacy redaction is preserved.

## DNS

The DNS Lookup Matrix covers the current resolver record families and reverse DNS. Historical DNS is marked provider-dependent rather than fabricated.

## Global map

The Live Global Map supports country hover/click, network observation points and provider-backed corporate/branch points. IP geolocation and corporate branch evidence are visually separated.

## DomainTools

DomainTools web pivots are available without credentials. Licensed API integration is available through `PHISHHUNTER_DOMAINTOOLS_API_KEY` for Domain Profile, WHOIS Lookup and Iris Investigate.
