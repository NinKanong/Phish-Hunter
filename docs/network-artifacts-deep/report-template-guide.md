# Report Template Guide

The HTML/PDF report is organized as:

1. Executive summary
2. Evidence inventory and cryptographic hashes
3. Findings and behavioral detections
4. Attacker behaviour reconstruction (observable network behavior only)
5. Network relationship graph
6. IOC explorer
7. MITRE ATT&CK candidate mapping
8. Unified timeline
9. Incident-response workflow
10. Threat-intelligence connector status
11. Limitations and analyst notes

The report intentionally distinguishes observation, heuristic interpretation, and unknowns.
